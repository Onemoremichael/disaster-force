# Models

Quantitative work will be delivered as an editable `.xlsx` workbook. Markdown documentation in this directory will define the model before authoring begins.

Planned modules:

1. Assumptions and scenario control
2. Mission demand and concurrency
3. Force inventory and readiness
4. Acquisition schedule and capitalization
5. Workforce and training pipeline
6. Operations, support, and recapitalization
7. Industrial capacity and learning curves
8. Deployment scenario capacity
9. Benefits and avoided-loss ranges
10. Sensitivities, checks, and sources

No model output should be treated as evidence unless its inputs are sourced or explicitly marked as design-study assumptions.
