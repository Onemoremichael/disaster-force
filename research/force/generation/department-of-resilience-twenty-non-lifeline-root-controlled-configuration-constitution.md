## Decision: compete where the work happens

A root is now a complete system organized around one **mechanism center**: the place and physics through which it carries, transforms, verifies and regenerates service. It is not a platform label. Every root retains every route and all seven service stages; the mechanism center determines how the complete chain is attempted.

## A configuration cannot differ only by branding

Each root freezes a twelve-domain vector: force path, access field, energy path, working medium, process locus, spatial topology, control distribution, perception and time, public-service seam, production process, repair path and residual path. The four anchor domains—force path, access, energy and working medium—must all differ within a system. Every within-system pair must differ in at least eight of twelve domains.

All thirty pairs pass that paper test. The floor is deliberately severe: a new supplier, fuel, software stack or vehicle host cannot preserve a root letter when the governing physical and industrial chain has converged. The vector is configuration control, not diversity evidence. Pass 175 still requires twelve accepted, root-exclusive ancestry identities and fourteen conjunctive `G3` gates per root.

Each root also receives one keystone experiment with a fatal result. Pelagic entry dies if port denial breaks complete flow; the sky bridge dies if it needs ballast or runway; the civic grid dies if a household disappears from accountable state; air-and-skin reach dies if occupied access cannot be lawful; the boundary field dies if local interactions amplify the hazard; mobile care dies if motion separates therapy or destination; microfactories die if disconnected output cannot reproduce calibration and ancestry. A safely contained adverse result remains evidence, not a schedule exception.
