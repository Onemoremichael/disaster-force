# RBB-1 — Root A QE-02 class execution and source-transfer qualification constitution

## Decision abstract

`RBB-1` defines the complete twenty-four-cell `QE-02` class after one accepted source-bearing seed event under [RBA-1](f36-cisa40-sa6-root-a-first-qe02-source-event-and-source-exposed-regeneration-constitution.md). Its subject is not twenty-three informal repetitions. It is the institution that must preserve exact cell identity, source-package ancestry, valid adverse results, no-flame outcomes, contamination carryover, outside-origin reconstruction and bounded authority while converting one 100-kilogram event into transferable evidence.

The first result is a prospective correction to the inherited reserve system. `RAE-1` provided twenty-four active source packages, four method–root-family reserves and only three source-bearing reserve tokens. Conditional on one successful RBA-1 seed and a nominal independent attempt-validity rate of 0.88, that topology has only a 41.8498-percent probability of obtaining all remaining required valid events. A pooled twenty-six-attempt binomial calculation would report 61.8891 percent, but it is inadmissible because packages and ancestry roots are not freely exchangeable across the four method–root families.[1–3]

RBB-1 therefore amends the bank before another source event may issue. Each of the four method–root families receives six active packages, five event-capable reserve packages and one untokened forensic reference package. The class bank becomes forty-eight serialized 125-kilogram packages: twenty-four active, twenty operational reserves and four protected references. Twenty reserve tokens may activate only after independent invalidity and only within the same cell and family. At a validity rate of 0.80, the conditional planning probability of completing the class becomes approximately 95.9294 percent; at 0.88 it becomes approximately 99.7184 percent. These are capacity calculations, not claims about physical success.

The reserve expansion is not permission to repeat an unfavorable result. A valid adverse attempt permanently blocks source-transfer qualification for its cell under this constitution. A reserve follows only `INVALID`, receives a new package, issue, baseline, packet and source-exposed regeneration cycle, and retains every prior attempt in the denominator. Up to five consecutive invalid replacements can be supported within a family, but the family reference package remains sealed even after maximum authorized use.

The class preserves four analytical populations. The attempt population contains every issued event, from the required twenty-four through the forty-four-attempt maximum. The admission-credit population contains exactly one creditable valid result per cell. The flame-exposed population contains only `AM-06` cells in which the registered ignition opportunity produced flame. The no-flame population contains valid `AM-06` opportunities without flame. No denominator can be substituted for another.

This separation produces two class decisions rather than one inflated label. `QE-02 SOURCE-TRANSFER` requires all twenty-four admission cells, all source-exposed returns, every root and campus decision, fixed aggregate environmental and unaccounted-source budgets, and complete outside-origin replay. `QE-02 FLAME-STATE TRANSFER` additionally requires flame exposure in all twelve `AM-06` rig–root cells. Valid no-flame earns source-admission credit but leaves the corresponding flame-state cell open. It cannot be repeated merely to manufacture flame coverage.

Every attempt remains a complete RBA-1 event. Forty-four attempt positions create capacity for 1,408 event-gate decisions, 9,020 dossier bindings, 1,584 safeing-path proofs, 2,112 root-specific measurements, 352 samples, 704 source-exposed regeneration work packages, 528 re-entry decisions and 1,056 outside-origin replay decisions. Base evidence is 2,823.816 GB native and 3,670.9608 GB allocated. Maximum attempt capacity requires 5,176.996 GB native and 6,730.0948 GB allocated. All originals coexist; invalid packets are not overwritten.

The class uses one fixed factorial schedule. The RBA-1 draw rotates six canonical rig sequences and independently flips method and root bits so that the accepted seed occupies inference position one. The remaining twenty-three primary cells retain the predeclared schedule. Execution occurs in tranches of at most three concurrent source events—one per campus—because six simultaneous events would consume all 336 event-duty seats and leave inadequate regeneration, evidence and relief capacity. Analytical waves and calendar tranches are therefore distinct and explicitly joined.

Source-exposed reuse governs inference. Each attempt consumes its incoming credential, completes sixteen regeneration work packages and twelve re-entry decisions, and receives a distinct baseline no earlier than day fourteen. A successor on the same rig then requires a new 96-hour freeze. The minimum same-rig interval remains 432 hours. The model provides eighteen required between-cell transitions and capacity for thirty-eight consecutive-attempt transitions if every reserve is used.

Class environmental and uncertainty accounts do not expand when reserves activate. Environmental source is capped at 0.10 kilograms per creditable event and 2.40 kilograms across all attempts. Unaccounted source is capped at 0.75 kilograms per creditable event and 18 kilograms across all attempts. An invalid attempt therefore consumes the same fixed class budgets; replacement does not create additional release or accounting allowance.

`RBB-1` uses the 384-position establishment already assigned by RAE-1. Three 56-position event units use 168 positions. Ninety-six positions operate campus regeneration and hazardous-material return. Forty-eight positions own evidence, replay and independent boards. Seventy-two provide relief, source-bank, environment, schedule and class-command capacity. This is a standing public test formation, not an ad hoc project office.

The eighteen-month stage allocates USD 48 million in capital, USD 20 million per year in support and USD 140 million in cross-classified technology work. Stage exposure is USD 78 million. After RBB-1, the `RAS-1` parent retains USD 176 million capital, USD 35 million per year and USD 315 million of technology authority for later source classes. Cumulative child-stage exposure becomes USD 728 million against the parent’s USD 1.2075 billion gross exposure. The release-aware chain reaches month 90, compared with month 114 sequentially; the 24-month difference remains conditional preparation time.

The companion model contains forty-one sheets. It begins with the RBA-1 seed unresolved, all remaining attempts open, reserve tokens dormant and every downstream authority blocked. Its 128 executable cases test reserve topologies, probability thresholds, exact-cell replacement, valid-adverse retention, no-flame stratification, fixed aggregate source budgets, source-exposed re-entry, denominator integrity, financial boundaries and split downstream release; 200 planning audits pass. The saved-workbook scan finds zero formula errors. All sheets were rendered for review, with the two long registers inspected through bounded first-eighty-row frames, and the OpenXML package validates without compression errors. The 176,258-byte artifact has SHA-256 `8506cbbd499a214dfde3a45c789fe03f71619ff5ec33a59a967e68b03454f9ff`. Planning checks do not assert that any physical event occurred.

An accepted source-transfer class can permit constitution of a 250-kilogram `AM-05 QE-03` event. `AM-06 QE-03` remains blocked unless all twelve flame-state cells close or a separate ignition-opportunity repair constitution resolves the missing flame evidence. Candidate admission, the 150-millimetre route, production and exterior rendering remain blocked.

## 1. Stocktake: from a source event to a source class

RBA-1 established that one cell could, in principle, receive an exact source package and create a bounded result. It did not establish that the result transfers across method, root, rig, campus, package, crew, regenerated baseline or event order. RBB-1 changes the unit of proof again.

| Stage | Evidence object | Question resolved | Maximum possible authority |
|---|---|---|---|
| `RAZ-1` | complete zero-source class | can the public system reproduce and transfer observed zero? | qualify `QE-01` |
| `RBA-1` | first 100 kg source event | can one freshly selected cell admit, account for and recover source? | one admission cell credit |
| `RBB-1` | complete 100 kg source class | do source and return claims survive every rig, method, root and campus? | bounded `QE-02` source transfer |
| later work | 250 kg and larger classes | which low-source relations survive increased inventory and duration? | separately constituted escalation |

The class proposition is:

> Can all twenty-four public rig–method–root cells execute the RBA-1 source event, preserve every valid, invalid, adverse and no-flame result, regain distinct source-exposed credentials, reconstruct every active packet outside its origin campus and close fixed class-wide custody budgets without borrowing evidence across cells?

An affirmative answer remains narrow. It supports the 40-millimetre `REA-100` low-source regime. It does not qualify the 150-millimetre reference route, 500-kilogram state, casualty-area fire, candidate mechanism, production article or operational vehicle.

## 2. The inherited reserve plan fails the class question

### 2.1 Why pooled binomial capacity is the wrong model

After one accepted RBA-1 seed, twenty-three admission credits remain. If three replacements were freely exchangeable, the nominal chance of obtaining twenty-three valid attempts from twenty-six at (p=0.88) would be:

\[
P(X\ge23)=\sum_{k=23}^{26}{26\choose k}p^k(1-p)^{26-k}
\approx0.618891.
\]

That result is already weak for a public class campaign. More importantly, it is not the source-bank topology. Each reserve package belongs to one of four method–root families. One family’s optical/electrochemical ancestry, assay and conditioning chain cannot be reassigned after failure to another family without changing the proposition.

With one accepted seed in a family of five remaining primary cells, and three other families of six, the inherited plan permits at most one reserve in any family and only three reserve activations overall. Let (q=1-p). Conditional completion is:

\[
p^{23}
\sum_{S\subseteq\{1,2,3,4\},\ |S|\le3}
\prod_{f\in S}n_fq,
\qquad n=(5,6,6,6).
\]

At (p=0.88), this equals approximately 0.418498. The gap from 0.618891 is the cost of ancestry partitioning and the three-token ceiling. It is a real capacity loss, not a statistical detail.

### 2.2 Selected reserve topology

For a family needing (s) successes with (r) available replacements, the probability of completing before the family capacity is exhausted is:

\[
P_{s,r}(p)=\sum_{j=0}^{r}{s-1+j\choose j}p^s(1-p)^j.
\]

RBB-1 selects five event-capable reserves per family. Conditional on one successful seed, class completion is:

\[
P_{5,5}(p)\times P_{6,5}(p)^3.
\]

| Nominal independent validity | Conditional class completion | Interpretation |
|---:|---:|---|
| 0.70 | 0.746120 | still inadequate; common causes likely dominate |
| 0.75 | 0.882747 | insufficient for planned class assurance |
| 0.80 | 0.959294 | selected minimum planning case |
| 0.88 | 0.997184 | reference planning case |
| 0.90 | 0.998966 | capacity, not reliability evidence |

The probability calculation assumes independent validity and no valid adverse outcome. It therefore cannot predict successful qualification. It answers only whether the institution has enough family-correct capacity to survive invalid observations.

## 3. Cells, attempts, credits and strata

The class uses four distinct identities:

- a **cell** is one rig–method–primary-root proposition;
- an **attempt** is one issued source event with one package, baseline and packet;
- an **admission credit** is the one creditable valid result that can close a cell; and
- a **flame-state credit** is an `AM-06` admission credit in which registered ignition produced observed flame.

Every cell needs one admission credit. A valid `SUCCESS-CONTAINED`, `SUCCESS-FLAME` or `VALID-NO-FLAME` result may supply it. A valid adverse result supplies no credit and cannot be replaced. `INVALID` supplies no credit but may release the next same-cell, same-family reserve token.

`VALID-NO-FLAME` is not half an event. It proves source issue, ignition opportunity, containment, safeing, custody, recovery and return while observing no flame. It closes the admission cell and enters the no-flame stratum. It does not close the flame-state cell.

### 4.2 Inference waves are not calendar simultaneity

The first inference wave contains the inherited seed and five later events. Those six results are balanced analytically, but the seed necessarily predates class issue. RBB-1 therefore separates:

- **inference position**, which protects factorial balance and carryover order;
- **calendar tranche**, which controls people, rigs, source custody and regeneration; and
- **attempt sequence**, which inserts lawful replacements without renumbering cells.

At most three source events occur concurrently, one at each campus. A reference execution pattern is:

| Block | Nominal day from seed | Primary events | Purpose |
|---|---:|---:|---|
| seed | 0 | 1 | accepted RBA-1 event |

The dates are capacity references, not physical schedules. An invalid attempt inserts a same-cell replacement after source-exposed return. A rig cannot advance to its next treatment until the invalid cell is either credited or declared capacity-exhausted. Other rigs may proceed only under a documented common-cause and balance review.

## 6. Source, environment and water accounts

### 6.1 Package custody

Each 125-kilogram package retains the RBA-1 split: 100 kilograms event source, 10 kilograms retained assay, 10 kilograms conditioning and 5 kilograms quarantine. Ten characteristics remain package-specific. A reserve package cannot reuse an active package’s assay or characteristic decision.

Every issued package has one terminal disposition: consumed event package, quarantined investigation package or unused reserve. The four family references remain sealed and separately stored. Package counts, event mass and gross custody reconcile independently.

### 6.2 Fixed class budgets

Public water remains a separate conserved account. The 120 m³ per-attempt casualty package protects people and the site. Public quench, rain, foam and runoff are summed across the class, but no water quantity is credited to method performance.

## 7. Source-exposed regeneration and carryover

Each attempt produces one pair-cycle record joining incoming baseline, source issue, terminal state, forensic hold, sixteen work packages, twelve re-entry decisions and the new baseline. `AVAILABLE` is a calculated conjunction. Cleanup, inspection or a favorable blank alone cannot create it.

Base execution creates twenty-four pair cycles and eighteen between-cell transitions. Maximum reserve use creates forty-four pair cycles and thirty-eight consecutive-attempt transitions. A transition records:

- actual predecessor and successor attempt tokens;
- whether it is within-cell replacement or between-cell progression;
- elapsed hours between `T0` events;
- predecessor source and water residuals;
- dry-zero, water-blank and source-blank decisions;
- replaced wetted articles and seals;
- calibration and safeing regression;
- ancestry cross-contamination result;
- prior and successor baseline identities; and
- accepting evidence root.

Every transition requires at least 432 hours. A replacement follows the invalid token, not the schedule placeholder. All later crew, rig, campus and carryover records follow the actual attempt sequence.

## 8. Root, method, rig and campus inference

### 8.1 Unlike-root agreement

Both roots observe every event; one is preassigned as primary for the cell. Twelve fixed rig–method contrasts compare primary-root decisions after both corresponding cells credit. The registered comparison set includes terminal-source time, total terminal mass, environmental source, unaccounted source, ancestry recovery, cross-talk, occupied area and water state.

A contrast cannot average terminal bins. It must show both cell results, both expanded uncertainties, their difference and the registered agreement interval. Missing or incompatible outcomes leave the contrast open.

### 8.2 Method distinction

`AM-05` and `AM-06` are not required to have equal burned mass, thermal field or recovery distribution. Fire is a different physical treatment. Twelve fixed rig–root method comparisons therefore ask whether both method-specific cells close their own bounds and whether source-account differences are causally reconstructable. They do not impose a false equality.

### 8.3 Rig and campus decisions

Each rig decision requires four admission credits, three accepted between-cell transitions, two root contrasts, two method comparisons and complete source-exposed return. Each treatment decision requires six admission credits across all rigs and campuses. Each campus decision requires eight credits, all required local returns and every non-origin replay of its originating attempts.

Rig or campus disagreement remains visible. A national class cannot average away a failed location merely because another location performed well.

## 9. Two transfer decisions

### 9.1 Source-transfer qualification

`QE-02 SOURCE-TRANSFER QUALIFIED` requires:

1. one exact admission credit in all twenty-four cells;
2. no valid adverse cell;
3. every issued attempt retained in the denominator;
4. all pair cycles and actual transitions accepted;
5. all twelve root contrasts and twelve method comparisons accepted;
6. all six rig, four treatment and three campus decisions accepted;
7. all active packets reconstructed at two non-origin campuses;
8. environmental and unaccounted-source class budgets closed;
9. all exceptions, changes and quarantines resolved; and
10. one immutable class packet accepted by independent authority.

### 9.2 Flame-state qualification

`QE-02 FLAME-STATE TRANSFER QUALIFIED` requires source-transfer qualification plus twelve flame-state credits, one for each `AM-06` rig–root cell. Any valid no-flame result keeps the corresponding flame-state cell open without invalidating its admission credit.

This split avoids two opposite errors. It does not discard no-flame evidence, and it does not call a source-handling class a fire-exposed class when some treatments never produced flame.

## 15. Falsifiers and stop conditions

The class stops or narrows if:

- fewer than twenty-four source-eligible cells remain after the seed;
- the forty-eight-package bank cannot preserve family identity and properties;
- an activated reserve targets a valid adverse result or a different cell;
- a family exhausts five operational reserves without credit;
- an invalid event disappears from any denominator;
- a no-flame result is repeated solely to obtain flame;
- an RBA-1 event gate is waived at class level;
- a source-exposed pair reuses its incoming baseline;
- an actual same-rig interval is below 432 hours;
- an invalid attempt receives a new environmental or unaccounted-source allowance;
- unlike roots exceed a registered comparison interval;
- a campus cannot reconstruct its non-origin packets;
- a class result relies on an available subset of rigs or cells;
- parent finance is exceeded or technology is counted twice; or
- any downstream release exceeds the split source/flame authority.

The correct response is a prospective amendment, root-cause program or narrower claim. It is not retrospective tolerance widening.

## 16. Research stocktake and next object

RBB-1 changes three conclusions from the prior frontier.

First, source-bearing reserve capacity is an experimental design variable. The inherited three-token plan looked adequate only when family identity was ignored. A serious Department must plan research attrition with the same care it applies to operational spares.

Second, fire opportunity and flame exposure are different evidence states. Preserving valid no-flame results yields a more honest source class and a more demanding thermal program.

Third, regeneration throughput is part of force projection. The class cannot scale by adding rigs alone; it needs hazardous-material return, evidence, independent boards, source banks and people available between events.

The next admissible object after successful source-transfer qualification is a 250-kilogram `AM-05 QE-03` source-entry constitution. `AM-06 QE-03` requires complete flame-state coverage or a separate ignition-opportunity repair constitution. That next pass should decide whether the 40-millimetre article remains physically honest as inventory and duration increase, how fixed class budgets change, and whether reserve topology must grow again.

Exterior rendering remains blocked.
