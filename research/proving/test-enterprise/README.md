# Innovation

Innovation begins where a complete mission thread fails. It does not begin with an invention seeking a disaster use.

[The resilience technology frontier](technology-frontier.md) converts performance gaps into rival research programs with measurable transition conditions. [The National Resilience Proving Network](national-proving-network.md) defines the laboratories, environmental ranges, flagship facilities, instrumentation, replication capacity, and independent test needed to turn promising prototypes into reproducible public knowledge.

The [NCAC full-mission test program](ncac-full-mission-test-program.md) applies that architecture to one formation. It proposes a twelve-year, $115.83 billion reserve-loaded evidence program spanning five powered human-system mechanisms, utility and occupied-district integration, twelve developmental 168-hour missions, thirty frozen-configuration confirmatory missions and two metropolitan replications. The [New York `L0` dossier](../campaigns/new-york/README.md) demonstrates the governing discipline: it builds the operator evidence surface and then withholds formal freeze when reproduction, inputs and custody are inadequate. The price is a design screen; the program's purpose is to earn rejection-quality knowledge before acquisition.

Novel capability receives force credit only when representative evidence changes a visible system parameter or uncertainty distribution. A successful component demonstration does not by itself mature a service chain or formation. If a candidate changes materially during confirmation, its trial count returns to zero.
