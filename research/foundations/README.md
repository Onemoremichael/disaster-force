# Foundations

Foundations defines the public promise before the institution or equipment. Its governing unit is a population or critical function, in a place and access state, requiring a service level over time after credible local restoration.

Read [First principles](first-principles.md) first. [Empirical baseline](empirical-baseline.md) bounds the observed problem without adding incompatible loss datasets. [Design reference missions](design-reference-missions.md) replaces the average disaster with compound and concurrent campaigns. [Service levels](service-level-library.md) defines the effect vocabulary; [mission engineering](mission-engineering-method.md) turns it into traceable service chains; and the [force-design framework](force-design-framework.md) converts demand into formations, readiness, movement, reception, sustainment, and regeneration. [Research program](research-program.md) defines how the inquiry should mature.

This layer owns requirements and method. It does not admit platforms or certify technical performance.
